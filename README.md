# 語音輸入（Windows 版）

按住快捷鍵說話，放開後文字自動出現在你游標的位置，可以用在 LINE、Word、瀏覽器等任何輸入框。

- **完全免費、完全離線**：語音辨識與 AI 整理都在你的電腦上完成，不上傳語音，不需要帳號或 API key。
- **自動加標點**：說出來的話會補上標點、去掉「嗯、呃」。
- **AI 整理**：可以把口語整理成通順的訊息、條列筆記或通知公告。

## 安裝

1. 到 [Releases](../../releases/latest) 下載 `VoiceInput-Setup.exe`。
2. 雙擊安裝。
3. 第一次啟動會顯示下載視窗，按「下載並開始」，等 AI 模型下載完成（只需一次）。

> **Windows 會跳出「Windows 已保護您的電腦」**：這是因為程式沒有購買數位簽章。點「其他資訊」→「仍要執行」即可。

## 使用

| 動作 | 效果 |
|---|---|
| 按住**右 Ctrl** 說話，放開 | 標點修整：補標點、去贅詞，不改內容 |
| 按住**右 Shift** 說話，放開 | 匯整：依風格整理成訊息或筆記 |

畫面下方會出現聲紋小視窗：紅色是標點修整、藍色是匯整，聲紋有跳動表示麥克風正常。

右下角系統匣（時鐘旁，可能收在 ^ 裡）的麥克風圖示，點右鍵可以：
- 切換**匯整風格**：禮貌訊息、輕鬆訊息、條列筆記、通知公告
- 開關「標點修整也用 AI」（關掉會更快，標點會比較陽春）
- 開機自動啟動
- 編輯自訂詞彙（常被聽錯的名字或專有名詞）
- 結束

## 電腦需求

| 項目 | 建議 |
|---|---|
| 系統 | Windows 10 / 11（64 位元） |
| 顯示卡 | **NVIDIA**，顯示記憶體 6GB 以上最佳 |
| 硬碟空間 | 約 8GB（模型下載後） |

程式會自動偵測顯示卡來決定使用的模型：

| 顯示記憶體 | 語音辨識 | AI 整理 | 首次下載量 |
|---|---|---|---|
| 10GB 以上 | 大型（準確） | 7B（最好） | 約 7.5GB |
| 6～10GB | 大型（準確） | 3B | 約 4.8GB |
| 4～6GB | 大型（準確） | 無 | 約 3GB |
| 沒有 NVIDIA 顯卡 | 小型（CPU，較慢） | 無 | 約 0.5GB |

沒有 AI 整理時，「標點修整」仍可使用（以語音辨識本身的標點為主），只是「匯整」無法使用。

## 疑難排解

| 狀況 | 處理 |
|---|---|
| 聲紋有跳但沒有文字 | 看畫面提示；到 設定 → 隱私權與安全性 → 麥克風，確認「讓桌面應用程式存取麥克風」已開啟 |
| 顯示「沒收到聲音」 | 同上，並確認預設錄音裝置是你要用的麥克風（設定 → 系統 → 音效 → 輸入） |
| 有辨識但沒有貼上 | 目標程式若以系統管理員身分執行，需要也用系統管理員開啟語音輸入 |
| 下載中斷 | 重新開啟程式，會從中斷的地方繼續下載 |
| 想完全移除 | 控制台移除程式後，刪除 `%LOCALAPPDATA%\VoiceInput` 資料夾（約 8GB 模型） |

紀錄檔在 `%LOCALAPPDATA%\VoiceInput\voice_input.log`，回報問題時請附上。

## 自訂

- **常被聽錯的詞**：系統匣 → 編輯自訂詞彙，一行寫一個詞。
- **自訂整理風格**：在 `%LOCALAPPDATA%\VoiceInput\prompts.json` 寫入 `{"風格名稱": "給 AI 的指示"}`，重新啟動後會出現在選單裡。

## 開發與自行打包

```bash
pip install -r requirements.txt
python app.py              # 直接執行
python -m unittest discover -s tests
```

安裝檔由 GitHub Actions 自動打包（`.github/workflows/build.yml`）：推送 `v*` 標籤時會建出 `VoiceInput-Setup.exe` 並發佈到 Releases。
